# Best City

Проект для определения лучшего города на основе различных критериев.

## Демо

Рабочая версия приложения доступна по адресу: [https://chic-vacherin-929f8b.netlify.app/](https://chic-vacherin-929f8b.netlify.app/)

## Описание

Это веб-приложение, которое помогает пользователям найти идеальный город для жизни, основываясь на различных параметрах и критериях.

## Технологии

- JavaScript
- HTML
- CSS

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/RuFalcon/best_city.git
```

2. Перейдите в директорию проекта:
```bash
cd best_city
```

3. Установите зависимости:
```bash
npm install
```

## Использование

Для запуска проекта выполните:
```bash
npm start
```
